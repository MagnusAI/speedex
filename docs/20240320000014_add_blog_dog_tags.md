# Add Dog Tags to Blog Posts

## Description
Added the ability to tag blog posts with one or more dogs, creating a many-to-many relationship between blog posts and dogs.

## Changes

### Database Updates
1. Created new `blog_post_dogs` junction table:
   - Links blog posts to dogs
   - Includes `created_at` timestamp
   - Has appropriate foreign key constraints
   - Includes indexes for better performance

2. Added RLS policies for the junction table:
   - Public read access
   - Authenticated users can insert/update/delete

### Type Updates
1. Updated `BlogPost` interface:
   - Added `dogs` array field
   - Imported `Dog` type

2. Updated `BlogPostFormData` interface:
   - Added `dog_ids` array field
   - Removed old tags field

### Component Updates
1. Enhanced `BlogPostForm`:
   - Added dog selection using Autocomplete
   - Added dog chips display
   - Improved form layout
   - Added loading states
   - Added error handling

### Service Updates
1. Created new `blog.ts` service with functions:
   - `createBlogPost`: Creates post with dog tags
   - `updateBlogPost`: Updates post and dog tags
   - `deleteBlogPost`: Deletes post
   - `getBlogPost`: Gets single post with dogs
   - `getBlogPosts`: Gets all posts with dogs

2. Added proper error handling and type safety

### Features Added
- Multiple dog selection in blog post form
- Visual display of selected dogs as chips
- Automatic handling of dog tag relationships
- Proper data fetching with related dogs
- Type-safe operations
