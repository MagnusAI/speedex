# Add Blog Feature

## Description
Implemented the blog system with CRUD operations, rich text support, and image handling.

## Changes

### Database
- Created `blog_posts` table with the following schema:
  ```sql
  create table blog_posts (
    id uuid default uuid_generate_v4() primary key,
    title text not null,
    content text not null,
    image_url text,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    updated_at timestamp with time zone default timezone('utc'::text, now()) not null
  );
  ```
- Added RLS policies for blog posts
- Created storage bucket for blog images

### Frontend Components
- Added `BlogFeed.tsx` component:
  - Responsive grid layout for blog posts
  - Card-based post preview
  - Loading and error states
  - Pagination support

- Added `BlogPost.tsx` component:
  - Rich text content display
  - Image support
  - Edit and delete functionality
  - Responsive layout

### Types
- Added `blog.ts` with interfaces:
  - `BlogPost` for complete post data
  - `BlogPostFormData` for form handling

### Navigation
- Added blog routes to the navigation drawer
- Implemented hash-based routing for GitHub Pages compatibility
